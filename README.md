# 학종 모의면접

학교생활기록부(생기부)를 읽고, 대학별 평가 기준에 맞춰 음성으로 질문하고, 답변을 받아 적어 꼬리질문과 평가 리포트를 주는 1인용 모의면접 웹앱입니다. 학생부종합전형의 생기부 기반 확인 면접을 실제 시간 압박 속에서 연습하려고 만들었습니다.

서버 하나를 내 PC에서 띄워 브라우저로 씁니다. 질문과 리포트는 Anthropic API(Claude)가 만들고, 음성 인식은 내 PC의 Whisper가 처리합니다.

## 기능

**면접**

- 학교별 모드: 면접 시간, 평가요소와 비중, 질문 성향이 학교마다 다릅니다. 지금은 아주대 첨단융합인재(첨단신소재공학과)와 인하대 인하미래인재 면접형(신소재공학과)이 들어 있습니다.
- 면접위원 2명이 음성으로 질문합니다. 지원 동기로 시작해 경험, 개념, 협업 순으로 깊어지고 마무리 질문으로 끝납니다.
- 모든 질문은 생기부의 특정 기록에 근거하며, 근거 문장이 원문에 실제로 있는지 서버가 대조합니다.
- 직전 답변이 추상적이거나 기록과 어긋나면 그 지점을 짚는 꼬리질문을 합니다.
- 전체 타이머와 답변 타이머가 있고, 시간이 다 되면 답변이 자동 제출됩니다.
- 음성으로 답하거나(녹음 후 전사) 글로 답할 수 있습니다. 마이크를 쓸 수 없으면 글 답변으로 바뀝니다.
- 실전 모드(질문을 글로 보여주지 않음), 압박 면접, 내 모습 보기(카메라 미리 보기)를 고를 수 있습니다.

**리포트**

- 종합 점수와 총평, 평가요소별 점수(학교별 비중 적용)
- 질문별 피드백: 잘한 점, 보완할 점, 다시 답한다면 넣을 내용의 방향, 생기부 기록과 어긋난 부분
- 답변마다 말하기 속도(분당 음절 수)와 침묵 시간, 녹음 다시 듣기
- 다음 연습에서 바꿀 3가지
- 모범 답안은 써 주지 않습니다. 외운 답은 꼬리질문에서 무너지므로 방향만 제시합니다.

**반복 연습**

- 같은 질문 다시 답하기: 피드백을 읽은 뒤 그 질문만 다시 답하고, 이전 답변과 비교한 평가를 받습니다.
- 지난 질문 피하기: 이전 연습에서 물어본 기록을 기억해 다른 기록에서 질문합니다.
- 연습 기록: 지난 리포트를 다시 열고 종합 점수의 변화를 봅니다.
- 예상 질문 목록: 면접 없이 생기부 항목별 예상 질문과 꼬리질문을 훑어봅니다.

## 구성

```
브라우저 ──────────────── 서버 (FastAPI) ─────────── Anthropic API
녹음, 타이머,             세션 상태, 생기부 마스킹     질문·꼬리질문·리포트 생성
질문 읽어 주기(TTS)       음성 인식(faster-whisper)    수상경력 이미지 전사
```

| 역할 | 사용 기술 | 실행 위치 |
| --- | --- | --- |
| 질문·꼬리질문·리포트 | Claude (`claude-sonnet-5-5`) | Anthropic API |
| 음성 인식 | faster-whisper `large-v3-turbo` | 내 PC (GPU, 없으면 CPU) |
| 질문 읽어 주기 | 브라우저 `speechSynthesis` | 브라우저 |
| 화면 | 빌드 없는 HTML, CSS, JavaScript | 브라우저 |

## 준비물

- Python 3.12와 [uv](https://docs.astral.sh/uv/), 또는 Docker
- [Anthropic Console](https://console.anthropic.com/)에서 발급한 API 키. Claude 구독과 별개로 사용량만큼 과금됩니다.
- NVIDIA GPU는 선택 사항입니다. 없으면 Whisper가 CPU로 돌아 전사가 느려집니다. 그 경우 `WHISPER_MODEL=small`로 낮추는 것을 권합니다.
- 브라우저는 Edge를 권합니다. 한국어 음성이 자연스럽고, 면접위원 두 명에게 서로 다른 목소리가 배정됩니다. Chrome도 동작하지만 음성이 기계적입니다.

## 설정

**1. 환경 변수**

`.env.example`을 `.env`로 복사해 채웁니다.

| 변수 | 설명 | 기본값 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | Anthropic API 키 | 없음 (필수) |
| `MASK_NAME` | 생기부에서 지울 지원자 이름 | 없음 |
| `MASK_SCHOOL` | 생기부에서 지울 고등학교 이름 | 없음 |
| `LLM_MODEL` | 질문과 리포트에 쓸 모델 | `claude-sonnet-5-5` |
| `WHISPER_MODEL` | 음성 인식 모델 | `large-v3-turbo` |
| `WHISPER_DEVICE` | `auto`, `cuda`, `cpu` | `auto` |
| `RECORD_SKIP_PAGES` | PDF 앞에서 건너뛸 쪽 수 | `0` |

`MASK_NAME`과 `MASK_SCHOOL`을 비워 두면 이름과 학교명이 그대로 API로 전송됩니다. 학교명은 앞부분만 넣어도 뒤에 붙은 "고등학교", "여자고등학교", "여고"까지 함께 지웁니다.

**2. 생기부 파일**

`data/records/` 폴더를 만들고 생기부 파일을 넣습니다. 폴더의 파일 전체를 하나의 생기부로 다룹니다.

| 형식 | 처리 |
| --- | --- |
| PDF | 텍스트를 추출합니다. 스캔본은 지원하지 않습니다. |
| png, jpg | 처음 한 번 LLM으로 전사하고 `data/records/.cache/`에 저장해 다시 씁니다. 표가 잘린 부분을 캡처해 넣는 용도입니다. |
| txt, md | 그대로 읽습니다. |

인적사항이 있는 첫 장은 빼고 넣는 것을 권합니다. 이미지 전사본은 준비 화면에서 펼쳐 볼 수 있고, 틀린 곳은 캐시 파일을 직접 고치면 됩니다.

## 실행

**Docker**

```bash
docker compose up -d --build
```

GPU를 쓰려면 호스트에 NVIDIA Container Toolkit이 있어야 합니다. GPU가 없는 환경에서는 `compose.yaml`의 `deploy` 블록을 지우고 실행합니다. 로그는 아래 명령으로 봅니다.

```bash
docker logs -f mock-interview
```

코드를 고친 뒤에는 같은 `docker compose up -d --build`로 다시 빌드합니다.

**로컬**

```bash
uv sync
```

```bash
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000
```

어느 쪽이든 브라우저에서 `http://localhost:8000`을 엽니다. 처음 실행할 때 Whisper 모델(약 1.6GB)을 내려받습니다.

## 사용 순서

1. **준비**: 학교를 고르고, 생기부가 제대로 읽혔는지 확인하고, 마이크 테스트와 질문 음성 들어 보기를 눌러 봅니다.
2. **면접**: 질문을 듣고 답합니다. 말이 끝나면 `답변 끝내기`를 누르거나 시간이 다 될 때까지 둡니다.
3. **리포트**: 30초쯤 뒤에 리포트가 나옵니다. 피드백을 읽고 약한 질문은 `이 질문 다시 답하기`로 바로 고쳐 말해 봅니다.

## 개인정보

생기부는 민감한 개인정보라서 아래 원칙으로 다룹니다.

- 생기부 텍스트는 이름과 학교명을 지운 뒤에만 세션 기록에 저장하고 API로 보냅니다. 주민등록번호, 전화번호, 이메일 형식도 지웁니다.
- 이미지 파일은 전사를 위해 원본 그대로 API로 한 번 전송됩니다. 이미지는 마스킹할 수 없으므로 인적사항이 함께 찍히지 않았는지 넣기 전에 확인하세요.
- 답변 녹음은 다시 듣기용으로 `data/audio/`에 보관합니다. 외부로 전송하지 않습니다. 전사한 텍스트는 평가를 위해 API로 전송됩니다.
- 카메라 화면은 브라우저에 비추기만 하고 녹화하거나 전송하지 않습니다.
- 서버 로그에는 소요 시간과 토큰 수만 남기고 생기부 본문과 답변 내용은 남기지 않습니다.
- `data/`와 `.env`는 git에서 제외되고 Docker 이미지에도 들어가지 않습니다.
- 서버는 `127.0.0.1`에만 열립니다. 로그인 기능이 없으므로 인터넷에 그대로 공개하면 안 됩니다. 다른 기기에서 쓰려면 Tailscale 같은 사설망을 거치세요. 마이크는 HTTPS나 localhost에서만 동작합니다.

## 비용

생기부 길이에 비례합니다. 아래는 약 4만 자(4만 3천 토큰) 분량의 생기부로 `claude-sonnet-5-5`를 썼을 때의 값입니다. 질문 생성은 실측이고 나머지는 작은 생기부의 실측에서 계산했습니다.

| 작업 | 대략의 비용 |
| --- | --- |
| 면접 한 판 (질문 8개와 리포트) | 0.32달러 |
| 같은 질문 다시 답하기 | 0.11달러 (5분 안에 이어서 하면 0.01달러) |
| 예상 질문 목록 | 0.14달러 (한 번 뽑으면 저장) |

생기부 전문을 프롬프트 캐시에 올려 두고 재사용합니다. 질문, 리포트, 다시 답하기는 출력 형식이 달라 캐시를 서로 나눠 쓰지 못합니다.

## 학교 추가

`app/schools.py`에 `School`을 하나 더 만들어 `SCHOOLS`에 넣으면 준비 화면에 나타납니다. 면접 시간, 평가요소와 비중(합이 100), 질문 성향, 인재상을 적습니다. 지금 들어 있는 값은 2027학년도 수시 모집요강과 입학처 안내를 참고한 것이므로, 실제 일정과 유의사항은 각 대학 입학처 공지를 따르세요.

## API

| 메서드와 경로 | 설명 |
| --- | --- |
| `GET /api/health` | 모델, 키 설정 여부, Whisper 상태, 생기부 파일 목록 |
| `GET /api/setup` | 준비 화면에 필요한 학교 설정과 생기부 상태 |
| `POST /api/sessions` | 면접 시작. 첫 질문을 돌려줍니다. |
| `POST /api/sessions/{id}/answers` | 답변 제출(음성 또는 글). 다음 질문이나 종료를 돌려줍니다. |
| `POST /api/sessions/{id}/report` | 리포트 생성. 한 번 만들면 저장한 것을 돌려줍니다. |
| `POST /api/sessions/{id}/turns/{index}/retry` | 같은 질문 다시 답하기 |
| `GET /api/sessions` | 끝낸 연습 목록 |
| `GET /api/sessions/{id}` | 세션의 문답과 리포트 |
| `GET /api/sessions/{id}/audio/{name}` | 보관한 답변 녹음 |
| `POST /api/preview` | 예상 질문 목록 |
| `POST /api/stt/test` | 마이크 테스트 |

## 폴더 구조

```
app/
  main.py          라우트
  schools.py       학교별 면접 설정
  prompts.py       프롬프트와 출력 스키마
  interviewer.py   LLM 호출 (질문, 리포트, 다시 답하기, 예상 질문, 이미지 전사)
  session.py       생기부 읽기, 세션 저장, 말하기 속도 계산
  masking.py       이름·학교명·연락처 마스킹
  stt.py           faster-whisper 래퍼 (cuda 실패 시 cpu)
  config.py        환경 변수와 경로
static/            화면 (index.html, app.js, style.css)
tests/             테스트와 가상의 생기부
data/              생기부, 세션, 녹음, 예상 질문 (git 제외)
```

## 테스트

```bash
uv run pytest
```

LLM과 음성 인식을 가짜로 바꿔 돌리므로 API 키와 GPU 없이 실행됩니다. `tests/fixtures/`의 생기부는 가상의 인물입니다.

## 한계

- 한 사람이 내 PC에서 쓰는 것을 전제로 만들었습니다. 로그인, 여러 사용자, 배포는 다루지 않습니다.
- 제시문 면접은 지원하지 않습니다. 생기부 기반 확인 면접만 다룹니다.
- 표정, 시선, 자세는 분석하지 않습니다.
- 말하기 속도의 "적당" 범위(분당 240~390음절)는 대략적인 기준이고, 음성 인식이 틀리면 수치도 달라집니다.
- 리포트의 점수는 모델의 판단입니다. 실제 면접위원의 평가와 같다고 볼 수 없으니 약점을 찾는 용도로 쓰세요.
